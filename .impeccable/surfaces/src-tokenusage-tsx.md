# Token usage

Mode: Operate. Scope: extend the existing workspace toolbar with recorded token usage and a project breakdown.

## Direction contract

THESIS: Make model consumption visible while work runs. A persistent count opens an inspectable breakdown; charts compare actual recorded amounts rather than implying an invented allowance.

OWN-WORLD: Inherit the current charcoal surfaces, ivory text, peach accent, DM Sans controls, tabular numerals, fine dividers and compact toolbar controls. No visual-system changes.

STORY: Read the workspace count, open the panel, compare saved projects, and expand a project for input, output, cache and current-build details. Missing provider reports and historical coverage remain explicit.

FIRST VIEWPORT: Place the count beside the model selector. The anchored, nonmodal panel has a clear total, a labeled input/output bar, and descending project rows. Escape and outside clicks dismiss it.

FORM: A compact toolbar disclosure and proportional horizontal bars within divided rows. Local extension; no concept seed applies. Keep the panel inside the viewport at desktop and mobile sizes.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
