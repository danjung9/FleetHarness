# Reuse research

Read requirements.md, scope.md and .fleet/packet.json. Write research.md with an adopt, adapt or reject decision for each relevant recipe candidate. Explain fit, integration effort and missing evidence. Preserve the original scope and requirements.

This phase inherits the global read, write, edit and bash tools for local workspace inspection and adds lexical search over supplied documents. Use available web search or network tools to inspect public sources. Candidate URLs are leads until inspected. Attribute only evidence actually inspected; mark licenses, versions, compatibility and operational integrations unverified when they cannot be checked. Do not fabricate research or claim a dependency was tested.

Hand concrete options, risks and open questions to the planning phase. Do not implement the application or write the implementation plan during research.
