# GenAI.mil demo setup

Open Model settings, choose GenAI.mil, then choose **Try demo setup**.
Select a sample model and choose **Use model in demo** to demonstrate the setup flow.

The demo is labeled throughout. It runs locally, needs no key, sends no requests,
and does not change the provider used by real builds. Exit the demo to return to
the existing live connection controls.

The sample model names come from the owner-supplied GenAI.mil API documentation.
They are examples, not a live catalog or an assertion that the current key can use
them. This change does not establish live authentication, inference, screenshot
review or end-to-end GenAI.mil builds.
