# Refined AppYard demos

39 ready-to-use Norfolk catalogue demos. Each numbered folder contains its own `index.html` and font licenses.

Copy a folder into the matching AppYard demo output and open `index.html`. All assets are embedded: no build, installation, API key, or backend is required. Cases 36 and 44 simulate synchronization inside the browser.

Folder numbers match the Norfolk catalogue. All demos use synthetic data and local browser state.
