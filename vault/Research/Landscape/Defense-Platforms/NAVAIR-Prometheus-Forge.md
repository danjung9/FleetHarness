# NAVAIR Prometheus Group's Forge

## Bottom line

[V, program self-description] NAVAIR Prometheus Group describes training warfighters and the DoW workforce to build useful software with AI. https://www.linkedin.com/company/navair-prometheus-group
[E] Public searches verified the training program but did not establish a Forge product manual, feature list or deployment boundary. [R] Treat Forge as a high-priority incumbent to inspect with the team, not as an empty space FleetHarness can claim. [R] Borrow the mission-user teaching model and verify the tool before asserting either superiority or duplication.

## What is actually verified

[V, program account] The group's public page describes training and infrastructure, one-day Warfighter Coder classes, Digital Warfare Officer cohorts, and a train-the-unit approach. It says its tools are free for DoW personnel and contract support. The page explicitly says it is for professional information sharing and does not represent official policy. The price statement applies to the program's tools generally; it is not a verified Forge commercial agreement. https://www.linkedin.com/company/navair-prometheus-group

[V, NAVAIR organizational post] NAVAIR's public account promotes a podcast on the Prometheus Group's AI-assisted warfighter coding course. This corroborates the program's existence, not every feature attributed to Forge. https://www.linkedin.com/posts/naval-air-systems-command_podcast-readiness-lethality-activity-7437944056187404289-DYhj

[V, program account] A cohort post describes work on analytics, SharePoint deployment, AI integration and document outputs. This supports training in practical delivery, without establishing a complete app factory or universal deployment authorization. https://www.linkedin.com/posts/navair-prometheus-group_dwo-ai-activity-7473454843660111872-MCU0

## Actual users and daily work

[V, program account] Public reports identify Navy and other DoW learners, including a Norfolk class with more than 30 warfighters. These are provider reports of participation, not an independent count of sustained production users. https://www.linkedin.com/company/navair-prometheus-group

[A] The likely daily pattern is selecting a local administrative problem, describing it to an approved coding tool, inspecting and refining the application, and using an available government hosting path. This is a hypothesis drawn from training descriptions. The exact Forge screens, export process and maintenance workflow were not observed.

[E] A named Forge production application, Navy unit acceptance record and independently measured time saving were not verified.

## Getting running and dependencies

[V, program claim] Prometheus says it helps users build and host solutions in existing environments using tools already available to them. https://www.linkedin.com/posts/navair-prometheus-group_dow-ai-dwo-activity-7485704159917203456--o9V

[A] A one-day class can be a useful familiarization path. It cannot be used as evidence that a new app obtains operational approval in one day. Useful work still needs an approved model/tool, allowed inputs, a supported runtime, distribution permissions and someone to maintain the result.

[E] Forge-specific contracts, model providers, authentication, accreditation, data connectors, offline ability, source ownership, installation duration and export format were not verified. No source reviewed supports assigning Forge a generic IL rating.

[R] Ask the program owner to show one synthetic use case from request through tests to export and execution. Record which steps need a developer, which need an administrator and which need approval. Keep that as a validation task; no outreach was performed for this review.

## Public criticism and evidence gaps

[E] Searches combining NAVAIR, Prometheus Group, Forge, AI, software and Warfighter Coder did not locate a product-specific public user criticism or audit. Results repeatedly confused this subject with unrelated deposition equipment and unrelated software named Forge. Those results were excluded.

[A] The unresolved risk is sustainment: an officer-built tool may depend on its original author, an approved host or a changing model service. This is a research question, not a documented Forge failure.

## Copy or avoid

- [R] Copy instruction anchored in the learner's real task and the practice of returning trained builders to their units.
- [R] Offer task examples, a visible test result and a clear handoff to a technical owner.
- [R] Avoid a new parallel training ecosystem if Prometheus already reaches the intended users.
- [R] Avoid counting a classroom prototype as accredited, maintained or demonstrated offline.
