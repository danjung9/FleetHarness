# Compare a disputed assumption

## Bottom line

[R] When a supplied limit is disputed, show two explicitly hypothetical branches of the same draft. [R] Highlight only consequences that differ and leave the disputed input unresolved. [A] An officer could then see whether settling that question changes the decision.

- **Moment [R]:** Compare invented 30-minute and 45-minute rest assumptions on the same fictional requests. Neither branch claims to represent Navy policy.
- **Novel increment [E/A]:** Existing notes require assumption approval and downstream invalidation. This adds a paired consequence comparison before the assumption is settled.
- **Judge evidence [R]:** One fixture should change feasibility; another should not. Both branches retain distinct inputs and check records. Official draft acceptance remains blocked until the responsible human resolves the assumption.
- **Size [A]:** 3 to 5 person-hours for separate branch state, comparison and review behavior.
- **Verdict [R]:** Kill for Thursday. Two plausible answers can confuse people or encourage choosing the convenient rule. Reconsider only if user observation shows unresolved assumptions are a frequent blocker. Never let a hypothetical branch inherit another branch's review.
