# Can the reviewer explain the rule?

## Bottom line

[R] Before revealing a result, ask the reviewer which of two synthetic drafts violates one supplied rule and why. [R] Reveal the check and discuss any mismatch. [A] This could expose an attractive interface that invites approval without understanding.

- **Moment [R]:** In a facilitated trial, show a fictional event ending at minute 60 with a supplied 30-minute rest requirement. Ask whether another event at minute 75 or 90 satisfies that rule.
- **Novel increment [E/A]:** Existing notes test software examples and ask people to inspect criteria. This measures the person's prediction and explanation before showing the software verdict.
- **Judge evidence [R]:** Record correct reasoning, confusion and help required without personal identifiers. Never convert a passed question into authorization or a user competence score.
- **Size [A]:** 0.25 to 0.75 person-hours for one independently checked question and a short trial record.
- **Verdict [R]:** Keep as a formative trial, with no required quiz in the product. Kill if it feels like an exam, prompts the answer, or adds burden without finding misunderstanding. Repeat one fresh example after clarification.
