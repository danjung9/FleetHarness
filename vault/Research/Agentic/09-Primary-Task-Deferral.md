# Primary-task deferral, round 1

## Bottom line

[R] Assign **agentic-builder** one factory correction after its current review return, serial integration and file release: preserve the original card task through intake and planning, then reject a plan that defers its defining outcomes. Require mandatory acceptance cases backed by independently reviewed synthetic inputs and expected outputs before counting the build satisfactory. Implement the coverage rule in existing skills and host gates; keep independent outcome judgment outside builder authority. This is one shared cause group for rejected challenges 8, 11 and 12, a proposed allocation rather than a dispatched task or implemented fix.
