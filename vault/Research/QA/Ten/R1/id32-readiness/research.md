## Concrete calculator risks from source inspection

DAG32 accepts a single deadline, target IDs and up to 200 nodes. Nodes have ID, predecessor IDs, integer duration or explicit `null`, nonnegative integer `readyAt`, and a nonempty source string. Validation rejects duplicate IDs, duplicate references and invalid integers; the common string-array helper caps a predecessor list and target list at 100. Time units, epoch and calendar meaning are not encoded. An adapter must not silently round fractional estimates or mix dates and durations; absence of a duration is not the same input as explicit `null`.

The recurrence is maximum of own availability and predecessor finishes, plus duration. `null` contributes zero only to the internal **lower bound**; unknown IDs propagate, and public finish/margin become `null` with status `unknown`. This internal bound must never be presented as a known completion or an UNKNOWN path as a proven critical path. A known finish yields deadline minus finish; zero margin is within the deadline in source code. Those behaviors are observations requiring later independent application verification, not test results.

Equal predecessor bounds are ordered by ID and only one representative path is returned. That can conceal equally controlling branches if the interface claims uniqueness. A node's delayed own availability can also control its start and shorten the displayed predecessor path. Upstream slack is not computed; target margin cannot be labeled upstream slack. Missing estimates anywhere in a target's prerequisite closure make that target unknown, even when a known branch is currently longer. This is conservative uncertainty handling, not proof of which unknown branch will ultimately control.

The source checks disconnected nodes too, so a cycle outside the chosen targets blocks analysis. Error text identifies unknown references but a cycle error does not enumerate cycle members. Recovery diagnostics may need additional application context. A node's source is merely validated as text: no cited record existence, source revision, freshness, asset match or trust is checked. Source strings must remain untrusted display data.

The primitive does not model shared personnel, competing parts, alternative equipment, probabilistic reliability or mission capability. In particular, two qualified personnel detaching cannot be reduced to a duration change without an explicit reviewed synthetic assumption. Timing alone provides no approved ranking across different capabilities or recommended operational actions.
