Open `index.html` directly in a modern desktop browser. Narrow browser layouts are implemented; device/browser approval and visual usability remain unverified. No server, install, network, account or credentials are required. The proposed field route is an owner-approved offline package on an approved device, subject to security review. Retain the previous complete package for rollback; export work before replacing files. No signed installer, update service, migration/import workflow or automatic rollback exists. Device-local browser storage may vary for file URLs; download/export and persistence must be checked on the selected browser before relying on them.
