Input format & demonstration baseline

Version 1 requires synthetic=true, bundleId, capturedAt and assets. Each asset requires assetId, type, evidenceId, revision, sourceTimestamp, controlId, controlRevision and excerpt. auditEnabled accepts true, false, null or an omitted value. Unknown and extra fields are rejected. IDs start with a letter and contain letters, digits, underscores or hyphens (1–80 characters). Source timestamps use UTC ISO format. Excerpts must exactly read auditEnabled=true, auditEnabled=false or auditEnabled=unknown.

Only training-service and SYN-AUDIT r1 are evaluated. Analysis date: 2026-11-04T00:00:00Z. The synthetic freshness window is 30 days inclusive; future or stale sources remain insufficient evidence.
