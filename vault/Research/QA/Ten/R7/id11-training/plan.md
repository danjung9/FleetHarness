## State and deliberate review boundary

Maintain raw text/dirty draft separately from last valid committed input/result. Initial proposals are inspectable even with conflicts; only feasible validate/negotiate results replace the valid board. Loading a fresh sample resets its local generation to revision 1 after deliberate save/discard if dirty. Apply changed input or Save edit creates a new revision, clears previous review and shows pending; invalid input preserves old board and exact draft. Show saved values beside conflicting candidates. While unsaved/unresolved draft changes exist, review/export are unavailable with an explanation. Discard restores saved values as the current pending-review revision; no past approval is silently reinstated. Review uses a labeled confirmation checkbox and explicit save; realApproval is permanently false. Persist raw draft, committed state and review generation in localStorage, disclose local-only synthetic storage and handle storage failure visibly. Rehydration validates stored shape and does not infer approval.

Prepare negotiation is an optional staged action allowing cancellation before submission; Optimize itself is one immediate action. During a running request show progress/status and budget, prevent duplicate runs and enable AbortController cancellation. Request-generation guards and worker termination prevent late writes. Cancel preserves committed board and review revision. Reset uses inline confirm/cancel, not a browser-native dialog that a declarative runner cannot control; cancellation preserves exact unfinished text, confirmation restores the original fixture, proposals and pending revision 1. Reload restores saved state, including locally-reviewed status only for the same saved revision.
