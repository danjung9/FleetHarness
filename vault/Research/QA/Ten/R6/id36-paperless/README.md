# Paperless Underway

A synthetic UC36 demonstration for expeditionary supply/admin staff and reviewers. It captures the supplied invented forms and seven-day task corpus, reviews exact revisions, and exercises a local peer synchronization simulation. **synthetic, not validated against the real format**. This build is generated and locally tested; host core evaluation currently fails on a suspected frozen ordering inconsistency; browser acceptance, final visual rechecks and owner acceptance remain pending.

## Prerequisites and quick start

Use Node.js 22.19 or newer and a current browser with IndexedDB, canvas and Web Crypto. No dependency installation, model, credential or remote API is required. The application uses only Node and browser platform APIs.

```sh
HOST=127.0.0.1 PORT=3000 node server.mjs
```

Open `http://127.0.0.1:3000/`. Keep that exact origin and port to retain browser storage. This is a device-local service: external connectivity can be absent, but the local Node service must remain running. A remote browser cannot compute if it loses access to this service. `file://` startup is unsupported. Stop the service with Ctrl+C.

## Main workflows

1. Choose **Load synthetic packet**, then **Extract forms**. Compare the source image and original text with the extracted review fields. The clean log should show 90 minutes, the requisition quantity 4, and correspondence enclosure REC-SUP. **All extracted fields and manual transcription** exposes the remaining fields and collections (collections use JSON arrays).
2. Correct fields, then **Validate packet**, **Save locally**, **Review packet**, and **Queue reviewed packet**. Saving commits a new immutable revision and returns review to pending. Review binds that exact committed revision. An unsaved change blocks routing. **Reload saved work** reloads the page and retained local state.
3. In **Weekly tasking**, choose **Consolidate week**. Review the original seven artifacts, select SYN-OPS or SYN-SUPPLY for A-03, then **Confirm owner decision** and **Review actions**. SYN-OPS yields verified IDs A-01, A-02, A-03, A-05; A-04/A-06 stay unresolved. Six source-linked status updates remain unsubmitted. **Generate filing recommendations** produces four fictional review dates and authorizes no disposal.
4. In **Reconnect and records**, choose **Load edit / edit conflict**, enter 7 in **Reviewed merge quantity**, then **Confirm both heads and merge**, **Review merged revision**, **Queue merged revision**, and **Connect local peer**. **Transfer with interrupted acknowledgement** retains offsets ATT-META 64 and ATT-PHOTO 384. **Pause sync** preserves work. **Resume sync**, **Finish transfer**, **Acknowledge peer**, and **Replay acknowledgement** should retain one RECEIPT-001. **File locally** records a local filing recommendation. Edit/delete recovery uses **Load edit / delete conflict** and **Retain live version**.
5. Use **Export reviewed package** for synthetic-packet.json, including sources, completed forms, reviewed routing package, task drafts, filing recommendations, revision IDs, audit and offsets. **Prepare current backup for import** fills **Synthetic packet JSON**; **Validate and import backup** checks schema and ID consistency before a transaction and requires fresh local review. Imported source text is never executed.
6. **Calculate fictional comparison** produces 15 minutes per packet and 2 synthetic hours across 8 packets from the preserved 24/9-minute fixture. **Run seeded error benchmark** checks the five fictional invalid scenarios and correction. These are not observed fleet benefits. Generate the pending review worksheet and transition checklist, or **Export path to fleet** for the one-page owner handoff.

## Recovery, storage and supported inputs

The supported formats are the supplied invented case-sensitive requisition/correspondence labels, controlled-English task grammar, and bounded font/layout raster templates documented in [data/README.md](data/README.md). The optical matcher compares actual rendered pixels with an explicit vocabulary; it crops the glyph area, excludes the ruling and treats near-paper grayscale as white. It is not general OCR, real handwriting recognition or official-form validation.

**Recovery scenarios and diagnostics** contains the faded/unsupported image and seeded-error samples, plus the clearly labeled storage-failure simulator. A faded duration stays uncertain until corrected. Unsupported images retain their source input and offer manual transcription. For a simulated save failure, use **Restore storage** then retry **Save locally**. Real storage failure requires freeing browser storage or exporting work while the page remains open. For service unavailability, restart Node on the same port and retry; drafts remain editable.

IndexedDB stores the packet, drafts, sources, revisions, review, receiver bytes, offsets, receipts and audit in one object transaction. Browser eviction, private browsing, user clearing and origin changes can remove it. This is **not encrypted storage**. Export regularly. There is no destructive reset control; loading a sample starts a new demonstration workspace, so export first. No automatic background transfer occurs. The peer is a simulation within this application, not authenticated transport or a cloud endpoint.

Text numeric quantities must be whole numbers 1 to 999; dates must be Gregorian YYYY-MM-DD; training duration must match same-day start/end. See the fixture guide for complete fictional validation rules. Backup schema is version 1 with classification synthetic and record objects. Imports never grant current approval. Do not use real records, credentials, official signatures or classified data.
