## Problem

Sailor-built tools stall on hosting, authorization and sustainment; a Beachmaster Unit's offline surf calculation app lacks approved hosting and a phone install path.

## What to build

Add AI-assisted spoken or typed entry with approval and logging, send results over a disconnected network, and produce a package with hosting option, install path, security evidence and sustainment owner.

## Requirements

- Offline on government mobile devices
- Human approval of every result
- Security evidence aligned to authorization
- Open maintainable code
- Includes a one-page path to fleet

## Named systems

- Modified Surf Index
