## Problem

Lessons learned are hard to find, judge for relevance and apply, so teams redo analysis or miss validated practices.

## What to build

A capability that takes a document or observation, searches JLLIS via an approved API or export, and returns source-cited relevant lessons with applicability factors and uncertainty, piloted on cyberspace assessments.

## Requirements

- Not tied to one organization or use case
- Recommend only, users accept, reject or edit
- Use approved JLLIS interface and preserve access controls
- Explain relevance beyond keyword matching
- Cite every source record
- Separate sourced practices from required actions
