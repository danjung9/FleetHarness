## Problem

Cloud-hosted DoW web apps are not consistently checked for security misconfiguration, complex access policies hide flaws, and every team struggles to integrate CAC/PKI login.

## What to build

Approved scanners for Cloud SRG and CIS AWS benchmark compliance and reusable open-source PKI authentication libraries for both operating systems.

## Requirements

- Cloud SRG compliance scanner for GovCloud
- CIS AWS benchmark scanner
- Open-source PKI library for Windows
- Open-source PKI library for Linux
- Output consistent with SCAP-equivalent standards

## Named systems

- AWS GovCloud
- Cloud SRG
- CIS Benchmarks
- CAC/PKI
- SCAP
- genai.mil
