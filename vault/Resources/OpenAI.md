# OpenAI

Source: event document 10, in our own words [P]. Setup status is in [[Setup/Codex]].

## Steps

1. Accept the FLEETHACKER invitation sent by email, signed in as the invited account.
2. In the API Platform, choose FLEETHACKER and its Default project, then create your own project API key.
3. Get a Codex client: the desktop app, or the extension for VS Code or Cursor.
4. If already signed in to Codex, sign out first. Then use the API key option: "Sign in another way" in the app, "Use API Key" in the extension.
5. Open your project folder and start.

## Limits

- Everyone creates their own project key and keeps it private.
- Never share an organization Admin API key.
- This setup covers local Codex only. Codex cloud needs a separate ChatGPT sign-in and is outside the event setup.

## Contacts

- Missing invitation or cannot see FLEETHACKER: events@defenseunicorns.com, from the email you registered with.
- OpenAI point of contact: rguardino@openai.com

The document also links Codex introductions, the IDE setup guide and sign-in guidance.

## Responsible use

From the event's OpenAI message, in our own words [P]:

- Codex may support approved projects, including certain military capability development, within OpenAI's national-security red lines.
- People must keep meaningful judgment and accountability over force and other consequential decisions.
- Projects must not enable mass domestic surveillance or get around legal requirements or oversight.
- Built-in refusals on weapons development stay active and must not be bypassed.
- Do not upload classified, controlled, sensitive or restricted government information unless the tool is authorized for it.
- Principles: https://cdn.openai.com/pdf/openai-principles-for-national-security-partnerships.pdf

[R] Check any project idea against this list before building. It fits rule 6, and a refusal mid-demo would be costly.

Event messages also list ChatGPT as an OpenAI tool, but document 10 only covers local Codex.
